# Инструмент визуализации графа зависимостей (pip)

## Общее описание
Учебный проект по дисциплине «Конфигурационное управление».
CLI-приложение для анализа и визуализации графа зависимостей пакетов Python (pip).
Реализован Вариант 6.

## Описание всех функций и настроек
Программа поддерживает следующие параметры командной строки:
- `--package` (обязательный): Имя анализируемого пакета.
- `--repo`: URL-адрес репозитория или путь к локальному файлу (по умолчанию: https://pypi.org/pypi).
- `--test-mode`: Режим работы с тестовым локальным репозиторием (файл JSON).
- `--version`: Версия пакета (по умолчанию: latest).
- `--max-depth`: Максимальная глубина анализа зависимостей (по умолчанию: 3).
- `--filter`: Подстрока для фильтрации пакетов (пакеты с этой подстрокой игнорируются).
- `--reverse`: Режим вывода обратных зависимостей.
- `--target`: Пакет для поиска обратных зависимостей (если отличается от --package).
- `--d2`: Вывод графа в формате языка диаграмм D2.
